Full-duplex voice (VAD barge-in)

When on, MS4 listens continuously through your mic. Voice activity detection (VAD) catches the moment you start speaking — even while MS4 is mid-sentence — fires a half-context barge-in (MS4's current word finishes its tail-off instead of cutting), plays an instant canned "Mhm?" / "Yes?" ack from the reflex catalog, and hands the captured audio straight to ASR. No mic button press required. This is the ChatGPT-mobile / Pi-style flow.

GPU passthrough (GPU-P / DDA / vGPU)

Three ways a VM can get GPU acceleration. GPU-P is the active path on consumer Windows 11 hardware (uses Hyper-V GPU Partitioning, no extra license). DDA is fully wired — the driver rebind works on consumer SKUs but the VM-attach step needs a Windows Server license to actually succeed. NVIDIA vGPU needs an active vGPU license server. All destructive actions require explicit confirmation.

Click Refresh snapshot to load capabilities + assignments.
GPU-P fast path (create game-stream VM)

Provisions a Windows 11 VM via the windows_game_stream_prebuilt template. GPU-P partitioning is wired by HiveMind inside the template. Works on consumer Windows 11 + any modern NVIDIA GPU. Name must match ^[A-Za-z0-9._-]+$.

DDA path (Hyper-V Discrete Device Assignment — wired for future WS license)

Rebinds a GPU to vfio-pci so a VM can claim it via DDA. Rebind works on consumer SKUs; the actual Add-VMAssignableDevice step needs Windows Server / Hyper-V Server. Use this once the license is acquired. Destructive: dismounts the GPU from the host.

vGPU partitioning (NVIDIA vGPU license required)

Creates one or more mdev instances on a GPU. Host must already be in vgpu mode. The call fails fast without an active NVIDIA vGPU license server. Server-validated count 1..64.
